# E2: グリッド線の灰色を明るく(視認性)

背景: 5分割などの「標準外」分割では、1/2・1/4(・n=3,6)以外の目盛りは全て灰色(0.4,0.4,0.4)で描かれ、暗い背景で見づらい。
色決定ロジック(確定, 4箇所で同一): 1/2位置=シアン(0.4,0.804,0.937) / 1/4・3/4位置=マゼンタ(0.937,0.4,0.933) / n=3,6=緑(0.4,0.937,0.667) / それ以外=灰色(0.4)。

| 場所 | 関数 | 内容 |
|---|---|---|
| 左ストリップ目盛り | `sub_1001A2C7C` @ `0x1001A2E0C`〜`E14` | 灰色ベースの `mov v0/v1/v2.16b, v8.16b` |
| レーン内の線(EditorKey) | `sub_1001B1544` @ `0x1001B16D4`〜`16DC` | 同(v9) |
| 他モードのレーン線 | `sub_1001B7AD8` @ `0x1001B7C38`〜`7C40` | 同(v11) |
| 同上 | `sub_1000C63E8` @ `0x1000C6548`〜`6550` | 同(v11) |

変更: 各3命令(計12命令, 各4B)を `FMOV S0/S1/S2, #0.75` に置換(ケイブ不要, 命令長不変)。
- 例: `0x1001A2E0C` `00 1d a8 4e`(ORR V0.16B,V8.16B,V8.16B) → `00 10 2d 1e`(FMOV S0,#0.75)
- 効果: 全ての分割で、灰色の目盛りが 0.4 → 0.75 に明るくなる(シアン/マゼンタ/緑は不変)。
- 生成: `tools/make_gray_patch.py <元Mach-O> 0.75` が旧バイト検証つきで仕様を出力 → `tools/apply_container.sh`
- ロールバック: `tools/apply_container.sh --restore` (直前のバックアップへ) / 元値に戻す場合は各 `new:old` を逆指定。
- 代替案(要望があれば): 標準外分割(5,7,9,10…)のみ別色(黄など)にする → コードケイブで n 判定が必要。
