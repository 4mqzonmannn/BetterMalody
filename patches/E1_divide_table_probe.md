# E1: 分割値テーブル probe (実験用。製品版には入れない)

目的: エディタが任意の分割値(5)を正しく扱えるか(グリッド線・吸着・保存)を確認する。

| 項目 | 内容 |
|---|---|
| 対象 | `Malody Mobile` (元バイナリ sha256 b3c5ebbc473c3218…) |
| VA / file offset | `0x10080AFA0` / `0x80AFA0` (__TEXT,__const `dword_10080AFA0`) |
| 旧 → 新 | `02 00 00 00` → `05 00 00 00` (テーブル[0] の 2 を 5 に) |
| 効果 | 分割メニューの最上段「1/2」ボタンが、値 **5**(1/5分割)として動作する(ラベルは「1/2」のまま) |
| 生成 | `tools/patch_bytes.py` → `work/e1/` → `build/BetterMalody_E1.ipa` (差分はこの1バイトのみ。cmpで確認済み) |
| ロールバック | `orig/Malody_Mobile_4.3.7.ipa` をPlayCoverに入れ直す |

## 確認項目 (PlayCoverで)
1. 分割メニューの最上段(1/2)を選ぶ → レーンのグリッド線が1拍を5分割になるか
2. ノートを置く → 5分割の線に吸着するか
3. 保存→再読込で `extra.divide=5` として復元されるか(強調はどのボタンになるか)
4. 他のボタン(1/3〜1/32)が従来どおりか
